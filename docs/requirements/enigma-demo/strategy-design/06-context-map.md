# 上下文映射

> 本文档定义 enigma-demo 限界上下文之间的协作关系和集成方式。

## 上下文关系概览

```text
┌────────────────────────────┐
│  应用运行上下文             │
│  Application Runtime        │
└─────────────┬──────────────┘
              │ CF
              v
┌────────────────────────────┐
│  角色任务准备上下文          │
│  Character Readiness        │
└───────┬────────────────┬───┘
        │ OHS + PL        │ CS
        v                 v
┌────────────────────┐  ┌────────────────────┐
│ 示例展示上下文       │  │ 规则验证上下文       │
│ Demo Presentation  │  │ Rule Verification  │
└────────────────────┘  └────────────────────┘
```

## 上下文关系详情

| 上游 | 下游 | 关系类型 | 说明 |
|------|------|----------|------|
| 应用运行上下文 | 角色任务准备上下文 | Conformist（CF） | 角色任务准备上下文服从 Enigma starter 和 Spring Boot 的装配模型 |
| 应用运行上下文 | 示例展示上下文 | Conformist（CF） | 示例展示入口复用 Spring Boot、Spring MVC 和 Maven 构建能力 |
| 角色任务准备上下文 | 示例展示上下文 | Open Host Service（OHS）+ Published Language（PL） | 核心上下文通过应用服务、API、DTO 提供稳定业务能力 |
| 角色任务准备上下文 | 规则验证上下文 | Customer-Supplier（CS） | 测试上下文作为客户，以业务规则验收核心上下文行为 |

## 关系类型说明

| 类型 | 符号 | 适用场景 |
|------|------|----------|
| Conformist | CF | 下游服从上游模型，不做业务模型转换 |
| Customer-Supplier | CS | 上游服务下游，下游可通过验收要求影响上游 |
| Open Host Service | OHS | 上游提供公开服务定义 |
| Published Language | PL | 使用公开语言通信 |
| Event-Driven Integration | EDI | 通过领域事件异步集成，发布/订阅解耦 |
| API Query Integration | AQI | 通过 API 实时查询上游数据，同步集成 |

## 详细关系描述

### 应用运行上下文装配角色任务准备上下文

```text
[应用运行上下文] --CF--> [角色任务准备上下文]
```

**描述**：角色任务准备上下文使用 Enigma DDD Spring 装配、Spring Boot 配置和 Maven 构建能力，不反向影响通用运行模型。

**数据流向**：应用配置、Bean 装配、启动生命周期从应用运行上下文流向核心上下文。

**接口定义**：Spring Boot 启动类、自动装配、Maven 构建配置。

### 角色任务准备上下文服务示例展示上下文

```text
[角色任务准备上下文] --OHS + PL--> [示例展示上下文]
```

**描述**：核心上下文通过应用服务或 REST API 暴露创建角色、查询角色状态、调整状态、更换装备、配置导力器等能力。

**数据流向**：命令从示例展示上下文进入角色任务准备上下文，查询结果以 DTO 或视图返回。

**接口定义**：创建角色命令、调整状态命令、更换装备命令、配置导力器命令、角色状态视图。

### 角色任务准备上下文接受规则验证上下文验收

```text
[角色任务准备上下文] --CS--> [规则验证上下文]
```

**描述**：规则验证上下文通过测试用例调用核心上下文行为，验证合法路径和非法路径。测试需求可反向推动核心上下文补齐错误语义。

**数据流向**：测试数据进入核心上下文，断言结果和异常从核心上下文返回。

**接口定义**：领域对象方法、应用服务方法、异常类型或错误码。

## 跨上下文领域事件

第一阶段不强制引入跨上下文领域事件。若后续需要展示 Enigma 事件能力，可预留以下事件作为候选。

| 事件名 | 发布方 | 订阅方 | 触发条件 | 事件内容 |
|--------|--------|--------|----------|----------|
| CharacterCreated | 角色任务准备上下文 | 示例展示上下文、规则验证上下文 | 角色创建成功 | 角色标识、名称、初始状态 |
| CharacterStatusAdjusted | 角色任务准备上下文 | 示例展示上下文、规则验证上下文 | 角色状态调整成功 | 角色标识、调整后的状态 |
| EquipmentChanged | 角色任务准备上下文 | 示例展示上下文、规则验证上下文 | 装备栏装备、替换或卸下成功 | 角色标识、装备栏位、装备信息、动作类型 |
| OrbmentConfigured | 角色任务准备上下文 | 示例展示上下文、规则验证上下文 | 导力器回路安装、替换或卸下成功 | 角色标识、槽位、回路信息、动作类型 |

## 防腐层设计（如适用）

第一阶段没有外部系统接入，不需要防腐层。

后续若接入完整游戏资料、外部物品库或第三方示例数据，应设置防腐层把外部模型转换为本地模型：

```text
外部装备/回路数据 --> 防腐层 --> 本地装备/回路配置对象
```
