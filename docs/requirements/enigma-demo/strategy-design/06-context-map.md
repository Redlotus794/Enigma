# 上下文映射

> 本文档定义 enigma-demo 限界上下文之间的协作关系和集成方式。

## 上下文关系概览

```text
┌────────────────────┐
│ Framework 上下文    │
└─────────┬──────────┘
          │ CF
          v
┌────────────────────┐      PL/OHS      ┌────────────────────┐
│ 地图系统上下文       │ ───────────────> │ 任务管理上下文       │
│ Map System          │                 │ Mission Management │
└─────────┬──────────┘                 └─────────┬──────────┘
          │                                      │
          │                                      │ CS
          v                                      v
┌────────────────────┐      CS          ┌────────────────────┐
│ 示例展示/规则验证    │ <────────────── │ 角色管理上下文       │
└────────────────────┘                 │ Character Mgmt      │
                                       └─────────┬──────────┘
                                                 │ CS
                                                 v
                                       ┌────────────────────┐
                                       │ 导力器系统上下文    │
                                       │ Orbment System     │
                                       └────────────────────┘
```

## 上下文关系详情

| 上游 | 下游 | 关系类型 | 说明 |
|------|------|----------|------|
| Framework 上下文 | 所有业务上下文 | Conformist（CF） | 业务上下文服从 Enigma、Spring Boot、Maven 和接口规范 |
| 地图系统上下文 | 任务管理上下文 | Published Language（PL）+ Open Host Service（OHS） | 地图公开地点、NPC、任务入口和剧情触发点标识，供任务管理引用 |
| 任务管理上下文 | 角色管理上下文 | Customer-Supplier（CS） | 任务管理引用角色作为任务执行者，不直接修改角色模型 |
| 角色管理上下文 | 导力器系统上下文 | Customer-Supplier（CS） | 导力器系统绑定角色标识并提供角色导力器视图 |
| 核心业务上下文 | 示例展示上下文 | OHS + PL | 核心上下文通过 API/DTO 对外展示 |
| 核心业务上下文 | 规则验证上下文 | CS | 规则验证上下文用测试验收业务规则 |

## 跨上下文领域事件

第一阶段优先使用同步 API 或应用服务。以下事件作为后续展示 Enigma DDD 事件能力的候选。

| 事件名 | 发布方 | 订阅方 | 触发条件 | 事件内容 |
|--------|--------|--------|----------|----------|
| CharacterCreated | 角色管理上下文 | 任务管理上下文、示例展示上下文 | 角色创建成功 | 角色标识、名称、初始状态 |
| CharacterStatusAdjusted | 角色管理上下文 | 示例展示上下文、规则验证上下文 | 角色状态调整成功 | 角色标识、调整后的状态 |
| OrbmentConfigured | 导力器系统上下文 | 角色管理上下文、示例展示上下文 | 导力器配置变化 | 角色标识、槽位、回路、属性值和导力魔法摘要 |
| LocationDiscovered | 地图系统上下文 | 示例展示上下文 | 地点可见或被查看 | 地点标识、地点元素摘要 |
| MissionAccepted | 任务管理上下文 | 地图系统上下文、示例展示上下文 | 任务被受理 | 任务标识、角色标识、任务来源 |
| MissionCompleted | 任务管理上下文 | 地图系统上下文、示例展示上下文 | 任务完成 | 任务标识、角色标识、完成时间 |

## 防腐层设计

第一阶段不接入外部游戏资料库。若后续接入《碧之轨迹》资料、地图数据或回路资料，应通过防腐层转换为本地模型：

```text
外部游戏资料 --> 防腐层 --> 地图系统 / 导力器系统 / 任务管理本地模型
```
