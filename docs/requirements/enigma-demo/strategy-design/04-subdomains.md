# 子域划分

> 本文档基于 enigma-demo 的业务能力划分子域，区分核心子域、支撑子域和通用子域。

## 子域类型定义

| 类型 | 说明 | 投入策略 |
|------|------|----------|
| **核心子域（Core Domain）** | 直接体现 demo 业务样例价值，是差异化的关键 | 第一阶段优先自研，重点表达业务规则 |
| **支撑子域（Supporting Subdomain）** | 支撑核心业务可运行、可验证、可学习 | 适度投入，保持实现简单 |
| **通用子域（Generic Subdomain）** | 通用技术能力，已有框架或 starter 可复用 | 优先复用 Spring Boot、Maven、Enigma starter |

## 子域划分

### 核心子域

| 子域名称 | 英文名 | 说明 | 包含的业务能力 |
|----------|--------|------|----------------|
| 角色任务准备 | Character Readiness | 表达特别任务支援科成员执行支援任务前的准备情况 | 创建角色、查看角色状态、调整角色状态、维护装备栏、配置导力器、拒绝非法操作 |

### 支撑子域

| 子域名称 | 英文名 | 说明 | 包含的业务能力 |
|----------|--------|------|----------------|
| 示例展示 | Demo Presentation | 面向使用者展示核心业务样例的运行方式和观察入口 | README 指引、示例接口、示例数据、关键代码导航 |
| 业务规则验证 | Business Rule Verification | 通过测试证明业务规则稳定可见 | 合法路径测试、非法路径测试、模块级 Maven 测试 |

### 通用子域

| 子域名称 | 英文名 | 说明 | 包含的业务能力 | 推荐方案 |
|----------|--------|------|----------------|----------|
| 应用运行 | Application Runtime | 提供应用启动、配置加载、依赖注入等通用运行能力 | Spring Boot 启动、配置管理、Bean 装配 | 复用 Spring Boot 与 `enigma-ddd-spring-boot-starter` |
| 构建与依赖管理 | Build and Dependency Management | 提供模块构建、测试执行、依赖版本约束 | Maven 构建、BOM 依赖管理、测试插件 | 复用 Maven、`enigma-bom`、`enigma-parent` |
| 接口与异常处理 | API and Error Handling | 对外接收命令、返回查询结果、表达错误 | HTTP 接口、DTO、异常响应 | 复用 Spring MVC 与项目 API 规范 |

## 子域与业务链路映射

| 核心链路 | 涉及子域 | 依赖关系 |
|----------|----------|----------|
| 支援科成员任务准备链路 | 角色任务准备、示例展示、业务规则验证、应用运行、接口与异常处理 | 角色任务准备提供领域规则；接口与异常处理暴露能力；业务规则验证覆盖路径；示例展示解释使用方式 |

## 投入优先级

| 优先级 | 子域 | 类型 | 投入资源 |
|--------|------|------|----------|
| 1 | 角色任务准备 | 核心子域 | 优先建模，优先测试，作为示例代码主体 |
| 2 | 业务规则验证 | 支撑子域 | 跟随核心行为同步补充测试 |
| 3 | 示例展示 | 支撑子域 | 在核心闭环可运行后补充 README 和示例入口 |
| 4 | 接口与异常处理 | 通用子域 | 采用项目既有 API 规范，不扩展复杂框架能力 |
| 5 | 应用运行、构建与依赖管理 | 通用子域 | 复用 Enigma 与 Spring Boot 现有能力 |

## 子域边界决策

第一阶段只设置一个核心子域"角色任务准备"。装备和导力器虽然可以发展为独立业务能力，但在当前 PRD 中仅用于表达角色准备情况，因此暂不拆成独立核心子域。
