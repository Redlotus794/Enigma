## 2. 背景与目标

### 2.1 业务背景

enigma-demo 第一阶段以克洛斯贝尔城市地图为入口，展示特别任务支援科成员如何在城市地点中查看 NPC、商店、任务和剧情元素，并结合角色状态与导力器配置推进支援任务。

### 2.2 设计目标

- 将角色管理、任务管理、导力器系统、地图系统拆分为独立核心上下文。
- 将 Spring Boot、Maven、接口 DTO、异常响应等通用能力统一收敛到 `Framework` 上下文。
- 保持第一阶段可运行、可测试、可解释，不扩展到完整战斗、库存和全游戏系统。

### 2.3 非目标

- 不设计战斗结算、完整库存、完整经济系统。
- 不实现完整《碧之轨迹》全部地图和任务，只以城市地图第一阶段元素作为样例。
- 不把 Framework 上下文拆成应用运行、构建、API 等多个通用子域。

## 4. 核心概念澄清

| 概念 | 所属上下文 | 本上下文含义 | 其他上下文使用方式 |
| --- | --- | --- | --- |
| 角色 | 角色管理 | 支援科成员，拥有身份、名称、等级、经验、HP、MP、CP、基础战斗属性和装备栏 | 任务管理仅引用角色标识；导力器系统引用角色标识绑定导力器 |
| 任务 | 任务管理 | 可发布、受理、推进、完成的支援任务 | 地图系统提供任务入口；展示上下文只使用任务视图 |
| 导力器 | 导力器系统 | 角色的回路配置系统，包含核心回路、普通回路、属性值和导力魔法结果 | 角色管理不直接修改导力器内部模型 |
| 地点 | 地图系统 | 城市区域下可被查看和挂载元素的位置 | 任务管理引用地点标识描述任务来源 |
| NPC | 地图系统 | 地点中的交互对象，可作为任务来源或剧情参与者 | 任务管理引用 NPC 标识作为任务来源 |
| 商店 | 地图系统 | 地点中的经营元素，第一阶段只展示，不设计完整交易 | 后续可拆分商业上下文 |
| 剧情触发点 | 地图系统 | 地点中的剧情推进元素，可触发任务或任务进度 | 任务管理引用触发点标识推进任务 |
| Framework | Framework | 通用技术能力集合，不承载业务语义 | 所有业务上下文服从其装配、构建和接口规范 |

## 5. 上下文详情

### 5.1 角色管理上下文

#### 核心职责

- 创建和查询特别任务支援科成员。
- 维护角色等级、经验、HP、MP、CP 和基础战斗属性。
- 维护角色装备栏中的武器、防具和两个饰品。
- 拒绝非法角色状态和非法装备栏操作。

#### 边界说明

**包含：**

- 角色创建、角色状态查询、角色状态调整。
- 武器、防具、饰品 1、饰品 2 的装备、替换和卸下。

**不包含：**

- 导力器槽位、回路属性值和导力魔法推导。
- 任务状态流转。
- 城市地图地点、NPC、商店和剧情触发点。

#### 领域模型候选

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 聚合 | Character | 角色管理聚合根 |
| 值对象 | CharacterStatus | 等级、经验、HP、MP、CP 和基础战斗属性 |
| 值对象 | BattleAttributes | STR、DEF、AGL、ATS、ADF、SPD、DEX、MOV、RNG |
| 值对象 | EquipmentLoadout | 武器、防具、饰品 1、饰品 2 的栏位配置 |
| 枚举 | EquipmentSlot | WEAPON、ARMOR、ACCESSORY_1、ACCESSORY_2 |
| 仓储 | CharacterRepository | 保存和查询角色 |

### 5.2 任务管理上下文

#### 核心职责

- 管理支援任务的发布、受理、推进和完成。
- 校验任务来源必须来自地图系统中的 NPC、地点或剧情触发点。
- 保证任务状态按有效顺序流转。

#### 边界说明

**包含：**

- 任务定义、任务来源、任务状态、任务剧情摘要。
- 发布、受理、推进、完成等业务动作。

**不包含：**

- 地图地点内部结构。
- 角色属性计算。
- 奖励发放、战斗结算和完整任务脚本系统。

#### 领域模型候选

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 聚合 | Mission | 支援任务聚合根 |
| 值对象 | MissionSource | 任务来源，可引用 NPC、地点或剧情触发点 |
| 枚举 | MissionStatus | PUBLISHED、ACCEPTED、IN_PROGRESS、COMPLETED |
| 值对象 | MissionStorySummary | 任务剧情摘要 |
| 仓储 | MissionRepository | 保存和查询任务 |

### 5.3 导力器系统上下文

#### 核心职责

- 按《碧之轨迹》最终形态设计导力器模型。
- 管理 1 个核心回路槽位和 7 个普通回路槽位。
- 维护回路安装、替换、卸下规则。
- 根据回路配置派生属性值和导力魔法结果。

#### 边界说明

**包含：**

- 角色导力器配置。
- 核心回路、普通回路、槽位、属性值汇总和导力魔法派生结果。

**不包含：**

- 角色基础状态。
- 回路来源、库存、购买和掉落。
- 战斗中导力魔法释放效果。

#### 领域模型候选

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 聚合 | Orbment | 导力器聚合根 |
| 值对象 | QuartzSlot | 回路槽位，区分核心槽位和普通槽位 |
| 值对象 | MasterQuartz | 核心回路 |
| 值对象 | Quartz | 普通回路 |
| 值对象 | SepithValue | 属性值 |
| 值对象 | ArtsFormula | 导力魔法派生规则 |
| 仓储 | OrbmentRepository | 保存和查询角色导力器 |

### 5.4 地图系统上下文

#### 核心职责

- 管理城市区域和地点。
- 管理地点下的 NPC、商店、任务入口和剧情触发点。
- 支持查看城市地点中的可交互元素。

#### 边界说明

**包含：**

- 城市区域、地点、NPC、商店、任务入口、剧情触发点。
- 地图元素归属地点的规则。

**不包含：**

- 完整世界地图、迷宫探索、寻路和战斗触发。
- 商店交易结算。
- 任务状态流转。

#### 领域模型候选

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 聚合 | CityMap | 城市地图聚合根 |
| 实体 | CityArea | 城市区域 |
| 实体 | Location | 城市地点 |
| 实体 | Npc | 地点中的 NPC |
| 实体 | Shop | 地点中的商店 |
| 值对象 | MissionEntry | 地点中的任务入口 |
| 值对象 | StoryTrigger | 地点中的剧情触发点 |
| 仓储 | CityMapRepository | 保存和查询城市地图 |

### 5.5 Framework 上下文

#### 核心职责

- 提供 Spring Boot 启动、Bean 装配和配置加载。
- 提供 Maven 构建、BOM 依赖管理和测试插件。
- 提供 HTTP 接口、DTO、异常响应和 Enigma DDD starter 的通用能力。

#### 边界说明

**包含：**

- 框架集成、构建和接口基础设施。

**不包含：**

- 角色、任务、导力器、地图中的任何业务规则。

## 6. 上下文映射

| 上游上下文 | 下游上下文 | 关系类型 | 集成方式 | 说明 |
| --- | --- | --- | --- | --- |
| 地图系统上下文 | 任务管理上下文 | Customer-Supplier + Published Language | API / 值对象引用 | 地图提供任务来源、NPC、地点和剧情触发点的公开标识 |
| 任务管理上下文 | 角色管理上下文 | Customer-Supplier | API / 值对象引用 | 任务引用执行角色，但不修改角色内部状态 |
| 角色管理上下文 | 导力器系统上下文 | Customer-Supplier | API / 值对象引用 | 导力器绑定角色标识，角色管理不直接操作导力器内部模型 |
| Framework 上下文 | 所有业务上下文 | Conformist | Spring Boot / Maven / DTO | 业务上下文服从统一框架能力 |
| 核心业务上下文 | 示例展示上下文 | Open Host Service + Published Language | REST API / DTO | 对外展示稳定业务能力 |
| 核心业务上下文 | 规则验证上下文 | Customer-Supplier | 测试调用领域行为和应用服务 | 测试以业务规则为验收标准 |

## 7. 暂不建模内容

| 内容 | 原因 | 后续规划 |
| --- | --- | --- |
| 完整战斗系统 | 会引入复杂计算和状态流转 | 后续作为独立战斗子域评估 |
| 完整库存和经济系统 | 当前只展示角色装备和地图商店 | 后续可拆分为库存/商店交易上下文 |
| 完整世界地图和寻路 | 第一阶段限定城市地图 | 后续扩展地图系统 |
| 完整剧情脚本系统 | 第一阶段只表达剧情触发点 | 后续扩展剧情上下文 |
