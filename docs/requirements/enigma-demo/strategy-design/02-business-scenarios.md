# 业务场景清单

> 本文档列出 enigma-demo 的主要业务场景，关注"做什么"而非"怎么做"。

## 场景分类

### 核心场景（Core Scenarios）

| 序号 | 场景名称 | 场景描述 | 触发条件 | 参与者 |
|------|----------|----------|----------|--------|
| 1 | 创建角色 | 登记特别任务支援科成员基础信息和初始状态 | 使用者需要新增一名可被管理的支援科成员 | 示例使用者、应用服务、角色状态上下文 |
| 2 | 查看角色状态 | 查看角色当前等级、HP、MP、CP、基础战斗属性、装备栏和导力器配置 | 使用者需要确认角色执行支援任务前的准备情况 | 示例使用者、查询接口、角色状态上下文 |
| 3 | 调整角色状态 | 更新角色等级、HP、MP、CP 或基础战斗属性 | 角色成长、受伤恢复或示例测试需要改变状态 | 示例使用者、应用服务、角色状态上下文 |
| 4 | 更换装备 | 为角色装备、替换或卸下武器、防具、饰品 | 使用者需要调整角色装备准备情况 | 示例使用者、应用服务、装备配置上下文 |
| 5 | 配置导力器 | 为角色安装、替换或卸下核心回路和普通回路 | 使用者需要调整角色导力器准备情况 | 示例使用者、应用服务、导力器配置上下文 |
| 6 | 拒绝非法业务操作 | 对违反业务规则的创建、调整、装备、导力器配置操作给出明确拒绝 | 命令参数或目标对象不满足业务规则 | 示例使用者、领域模型、测试用例 |

### 支撑场景（Supporting Scenarios）

| 序号 | 场景名称 | 场景描述 | 触发条件 | 参与者 |
|------|----------|----------|----------|--------|
| 1 | 示例运行指导 | README 指导使用者理解业务范围、运行 demo、定位关键代码 | 使用者第一次接触 enigma-demo | 示例使用者、文档 |
| 2 | 业务规则测试 | 用测试覆盖角色创建、状态调整、装备更换、导力器配置等规则 | 代码实现后需要验证规则稳定性 | 开发者、测试用例、Maven |
| 3 | 示例数据准备 | 提供少量支援科成员、装备、回路的示例数据或测试数据 | 展示或测试需要可读样例 | 开发者、测试工具 |

### 通用场景（Generic Scenarios）

| 序号 | 场景名称 | 场景描述 | 触发条件 | 参与者 |
|------|----------|----------|----------|--------|
| 1 | 应用启动 | Spring Boot 应用启动并加载 Enigma DDD Spring 装配 | 使用者运行 demo | Spring Boot、Enigma starter |
| 2 | 参数校验与异常响应 | 对外接口或应用服务把非法输入转换为清晰错误 | 使用者提交非法请求 | API 层、异常处理机制 |
| 3 | 依赖与构建管理 | 通过 Maven 统一构建、测试、运行 demo | 开发者执行构建命令 | Maven、enigma-bom、enigma-parent |

## 场景优先级

| 优先级 | 场景 | 理由 |
|--------|------|------|
| P0 | 创建角色 | 所有后续操作的业务前置，是示例工程的入口场景 |
| P0 | 查看角色状态 | 直接展示角色准备情况，是使用者理解领域对象的主要窗口 |
| P0 | 调整角色状态 | 展示基础属性规则和领域行为校验 |
| P0 | 更换装备 | 展示固定栏位、替换、卸下等业务规则 |
| P0 | 配置导力器 | 展示核心槽位、普通槽位、槽位占用等业务规则 |
| P0 | 拒绝非法业务操作 | 保证示例不是单纯 CRUD，必须体现业务约束 |
| P1 | 业务规则测试 | 验证 P0 业务规则，是交付质量要求 |
| P1 | 示例运行指导 | 保证 demo 可学习、可运行、可解释 |
| P2 | 示例数据准备 | 提升展示体验，但不改变核心业务模型 |
| P2 | 测试工具推荐用法 | 可选展示，不属于第一阶段业务闭环必需内容 |

## 第一阶段场景边界

第一阶段仅把"角色执行支援任务前的准备情况"作为业务闭环。任务接取、任务执行、战斗结算、经验成长、库存管理、装备属性加成和回路属性加成暂不纳入建模范围。
