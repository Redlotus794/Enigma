# 统一语言

> 本文档定义 enigma-demo 每个限界上下文内部的统一语言，是后续代码命名的来源。

## 使用说明

- 统一语言之前：PRD、战略设计、业务流程说明。
- 统一语言之后：Java 实体、值对象、接口、类、方法、命令、查询命名。
- 统一语言需在进入战术设计前确认。

## 上下文：角色任务准备上下文

### 术语表

| 术语 | 英文名 | 类型 | 解释 | 示例 |
|------|--------|------|------|------|
| 支援科成员 | Support Section Member | 实体 / 业务称谓 | 被管理的角色，来自特别任务支援科 | 罗伊德、艾莉 |
| 角色 | Character | 聚合 | 角色任务准备的核心对象，拥有状态、装备栏和导力器配置 | 一个已创建的支援科成员 |
| 角色标识 | Character Id | 值对象 | 系统生成的角色唯一标识 | `characterId` |
| 角色名称 | Character Name | 值对象 | 角色的显示名称，不能为空 | `Lloyd Bannings` |
| 角色状态 | Character Status | 值对象 | 等级、HP、MP、CP 与基础战斗属性的组合 | 等级 10，HP 1200 |
| 等级 | Level | 值对象字段 | 角色等级，不能小于 1 | `level = 1` |
| HP | Health Point | 值对象字段 | 生命值，不能小于 0 | `hp = 100` |
| MP | Magic Point | 值对象字段 | 魔法值，不能小于 0 | `mp = 40` |
| CP | Craft Point | 值对象字段 | 战技点，不能小于 0 | `cp = 0` |
| 基础战斗属性 | Battle Attributes | 值对象 | STR、DEF、AGL、ATS、ADF、SPD、DEX、MOV、RNG 的组合 | `str = 20` |
| STR | Strength | 值对象字段 | 攻击力，不能小于 0 | `str = 20` |
| DEF | Defense | 值对象字段 | 防御力，不能小于 0 | `def = 15` |
| AGL | Agility | 值对象字段 | 回避率，不能小于 0 | `agl = 5` |
| ATS | Arts Strength | 值对象字段 | 法术攻击力，不能小于 0 | `ats = 18` |
| ADF | Arts Defense | 值对象字段 | 法术防御力，不能小于 0 | `adf = 12` |
| SPD | Speed | 值对象字段 | 速度，不能小于 0 | `spd = 8` |
| DEX | Dexterity | 值对象字段 | 命中率，不能小于 0 | `dex = 6` |
| MOV | Movement | 值对象字段 | 移动力，不能小于 0 | `mov = 4` |
| RNG | Range | 值对象字段 | 攻击范围，不能小于 0 | `rng = 1` |
| 装备栏 | Equipment Loadout | 值对象 | 角色当前装备的武器、防具、饰品 1、饰品 2 | 武器栏装备警棍 |
| 装备栏位 | Equipment Slot | 枚举 | 可装备物品的位置 | WEAPON、ARMOR、ACCESSORY_1、ACCESSORY_2 |
| 装备 | Equipment | 值对象 | 安装在装备栏位上的物品配置 | 武器、防具、饰品 |
| 导力器 | Orbment | 值对象 | 角色安装核心回路和普通回路的配置载体 | 1 个核心槽位和 7 个普通槽位 |
| 回路槽位 | Quartz Slot | 枚举 | 导力器中的回路安装位置 | CORE、NORMAL_1 |
| 核心回路 | Master Quartz | 值对象 | 安装在核心回路槽位的回路 | 核心回路槽位只能有 1 个 |
| 普通回路 | Quartz | 值对象 | 安装在普通回路槽位的回路 | 普通槽位共 7 个 |
| 创建角色 | Create Character | 命令 | 创建支援科成员并登记初始状态 | 创建罗伊德 |
| 调整角色状态 | Adjust Character Status | 命令 | 更新等级、HP、MP、CP 或基础战斗属性 | 调整 HP |
| 更换装备 | Change Equipment | 命令 | 装备、替换或卸下指定装备栏位的装备 | 替换武器 |
| 配置导力器 | Configure Orbment | 命令 | 安装、替换或卸下指定导力器槽位的回路 | 安装核心回路 |

### 常用表达式（Ubiquitous Language Phrases）

| 业务表达 | 技术含义 |
|----------|----------|
| 创建支援科成员 | 创建 Character 聚合并校验 CharacterStatus |
| 查看角色状态 | 查询 Character 的状态、装备栏和导力器配置 |
| 调整角色状态 | 调用 Character 的状态调整行为 |
| 为角色装备武器 | 在 EquipmentLoadout 的 WEAPON 栏位放置 Equipment |
| 卸下饰品 | 清空 ACCESSORY_1 或 ACCESSORY_2 栏位 |
| 安装核心回路 | 在 Orbment 的 CORE 槽位放置 Master Quartz |
| 安装普通回路 | 在 Orbment 的 NORMAL_1 至 NORMAL_7 槽位放置 Quartz |
| 替换回路 | 用新回路覆盖指定已存在槽位的回路 |
| 非法业务操作必须被拒绝 | 领域行为抛出明确业务异常或返回失败结果 |

### 命令与查询

**命令（Command）：**

| 命令 | 触发条件 | 前置条件 | 后置结果 |
|------|----------|----------|----------|
| CreateCharacter | 使用者登记新的支援科成员 | 名称非空，等级不小于 1，数值不小于 0 | 角色被创建 |
| AdjustCharacterStatus | 使用者更新等级、资源值或基础战斗属性 | 角色存在，新状态满足业务规则 | 角色状态被更新 |
| EquipItem | 使用者为装备栏位装备物品 | 角色存在，装备栏位存在 | 指定栏位有装备 |
| ReplaceEquipment | 使用者替换已装备物品 | 角色存在，装备栏位存在 | 指定栏位装备被替换 |
| UnequipItem | 使用者卸下装备 | 角色存在，装备栏位存在 | 指定栏位为空 |
| InstallQuartz | 使用者安装回路 | 角色存在，导力器槽位存在 | 指定槽位有回路 |
| ReplaceQuartz | 使用者替换回路 | 角色存在，导力器槽位存在 | 指定槽位回路被替换 |
| UninstallQuartz | 使用者卸下回路 | 角色存在，导力器槽位存在 | 指定槽位为空 |

**查询（Query）：**

| 查询 | 返回内容 | 过滤条件 |
|------|----------|----------|
| GetCharacterStatus | 角色名称、等级、HP、MP、CP、基础战斗属性、装备栏、导力器配置 | 角色标识 |
| ListCharacters | 角色摘要列表 | 可选：名称关键字 |

## 术语冲突记录

| 术语 | 上下文 A 含义 | 上下文 B 含义 | 是否需要转换 |
|------|------------|------------|--------------|
| 角色 | 角色任务准备上下文中的聚合 | 示例展示上下文中的 DTO 视图 | 是，领域模型转换为展示视图 |
| 状态 | 领域对象可变更的业务状态 | 查询响应中的状态快照 | 是，内部状态转换为只读 DTO |
| 装备 | 装备栏位上的配置对象 | 展示响应中的装备信息 | 是，避免展示层直接持有领域对象 |
