# PRD 08 - 异常操作与验收标准

## 1. 异常操作处理

系统应拒绝明显不合法的业务操作。

需要拒绝的操作包括：

- 使用空名称创建角色。
- 使用小于 1 的等级创建或调整角色。
- 使用负数经验创建或调整角色。
- 使用负数 HP 创建或调整角色。
- 使用负数 MP 创建或调整角色。
- 使用负数 CP 创建或调整角色。
- 使用负数基础战斗属性创建或调整角色。
- 对不存在的角色进行查询或操作。
- 对不存在的装备栏位进行装备或卸下操作。
- 对不存在的导力器槽位进行安装、替换或卸下操作。
- 对不存在的城市区域或地点进行查询。
- 为不存在的地点配置 NPC、商店、任务或剧情触发点。
- 查询不存在的背包物品。
- 扣减超过背包持有数量的物品。
- 在不存在的商店购买物品。
- 购买商店不存在的物品。
- 对不存在的任务进行受理、推进或完成操作。
- 跳过任务状态顺序推进任务。

## 2. 测试与验收标准

- 角色创建规则必须有测试覆盖。
- 角色状态调整规则必须有测试覆盖。
- 装备栏更换规则必须有测试覆盖。
- 导力器配置规则必须有测试覆盖。
- 城市地图元素规则必须有测试覆盖。
- 背包物品数量规则必须有测试覆盖。
- 商店购买规则必须有测试覆盖。
- 任务状态流转规则必须有测试覆盖。
- 示例代码必须能通过模块级 Maven 测试。
- README 必须能指导使用者运行 demo 并理解示例业务。
