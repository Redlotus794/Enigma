# PRD 03 - 角色管理

## 1. 创建角色

系统应支持创建特别任务支援科成员，并记录角色的初始状态。

创建角色时需要填写：

- 角色名称。
- 初始等级。
- 初始经验。
- 初始 HP。
- 初始 MP。
- 初始 CP。
- 初始攻击力 STR。
- 初始防御力 DEF。
- 初始回避率 AGL。
- 初始法术攻击力 ATS。
- 初始法术防御力 ADF。
- 初始速度 SPD。
- 初始命中率 DEX。
- 初始移动力 MOV。
- 初始攻击范围 RNG。

创建角色时应校验：

- 角色名称不能为空。
- 初始等级不能小于 1。
- 初始经验不能小于 0。
- 初始 HP 不能小于 0。
- 初始 MP 不能小于 0。
- 初始 CP 不能小于 0。
- 初始基础战斗属性不能小于 0。

## 2. 查看角色状态

系统应支持查看角色当前状态，用于确认角色执行支援任务前的准备情况。

角色状态信息应包括：

- 角色名称。
- 当前等级。
- 当前经验。
- 当前 HP。
- 当前 MP。
- 当前 CP。
- 当前攻击力 STR。
- 当前防御力 DEF。
- 当前回避率 AGL。
- 当前法术攻击力 ATS。
- 当前法术防御力 ADF。
- 当前速度 SPD。
- 当前命中率 DEX。
- 当前移动力 MOV。
- 当前攻击范围 RNG。
- 当前装备栏。
- 当前导力器配置。

## 3. 调整角色状态

系统应支持调整角色的等级、经验、HP、MP、CP 和基础战斗属性。

调整角色状态时应校验：

- 等级不能小于 1。
- 经验不能小于 0。
- HP 不能小于 0。
- MP 不能小于 0。
- CP 不能小于 0。
- 基础战斗属性不能小于 0。

## 4. 更换装备

系统应支持为角色装备或卸下武器、防具和饰品。

装备栏应至少包含：

- 武器栏位。
- 防具栏位。
- 饰品栏位 1。
- 饰品栏位 2。

更换装备时应满足：

- 同一个装备栏位同时只能装备一件装备。
- 空装备栏位可以直接装备物品。
- 已占用栏位可以通过替换操作更换装备。
- 已占用栏位可以通过卸下操作变为空栏位。
