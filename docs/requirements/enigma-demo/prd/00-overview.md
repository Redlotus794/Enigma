# PRD 00 - 产品总览

## 1. 背景

Enigma 需要一个标准示例工程，用于展示业务项目如何围绕清晰的业务场景组织代码，并通过可运行样例帮助使用者理解框架的基本用法。

当前 `enigma-demo` 将从零开始重新设计，不沿用既有示例代码。

## 2. 产品定位

`enigma-demo` 是 Enigma 框架的标准示例工程，用于演示业务项目如何基于 `enigma-ddd-spring-boot-starter` 构建一个小而完整的业务样例。它不是玩具 CRUD，而是一个围绕明确业务规则组织的可运行示例。

## 3. 目标用户

- Enigma 框架使用者：通过 demo 学习如何创建标准业务项目。
- 后端开发者：参考 demo 理解业务规则如何在代码中表达、验证和演进。
- 框架维护者：通过 demo 验证 starter 的核心能力是否可用、易用、可解释。

## 4. 产品目标

- 提供一个从零开始的标准业务样例。
- 展示清晰的业务对象、业务动作和业务规则。
- 展示一个小而完整的业务样例，而不是面向数据库表的贫血 CRUD。
- 展示 `enigma-ddd-spring-boot-starter` 的基础使用方式。

## 5. 非目标

- 不追求完整业务系统能力。
- 不引入复杂数据库、中间件或外部系统依赖。
- 不把 demo 做成通用脚手架生成器。
- 不覆盖 Enigma 所有 starter 能力，只覆盖最基础、最常用、最能说明业务样例实现方式的能力。
