# PRD 02 - 业务场景

## 1. 第一阶段核心业务场景

第一阶段实现角色准备、任务推进、背包与商店支撑能力。特别任务支援科成员需要维护自己的基础状态、装备栏和导力器配置，并在城市地图中识别 NPC、商店、任务和剧情元素，用于表达角色在执行支援任务前后的业务状态。

## 2. 基础业务流程

- 创建角色：登记支援科成员的基础信息和初始状态。
- 查看角色状态：查看角色当前等级、经验、HP、MP、CP、基础战斗属性、装备和导力器配置。
- 调整角色状态：更新角色等级、经验、HP、MP、CP 或基础战斗属性。
- 更换装备：为角色装备或卸下武器、防具、饰品。
- 配置导力器：为角色安装、替换或卸下核心回路和普通回路，并查看由回路配置形成的属性值和导力魔法结果。
- 查看城市地图：查看城市区域、地点、NPC、商店、可接任务和剧情触发点。
- 管理背包：查看背包物品，增加或扣减物品数量。
- 商店购买：在城市地图中的商店购买物品并放入背包。
- 推进任务：通过城市地图中的 NPC、地点或剧情触发点受理、推进和完成支援任务。

## 3. 基础业务规则

- 角色名称不能为空。
- 等级不能小于 1。
- 经验、HP、MP、CP 和基础战斗属性不能小于 0。
- 同一个装备栏位同时只能装备一件装备。
- 空装备栏位可以装备物品，已占用栏位需要先卸下或替换。
- 导力器包含 1 个核心回路槽位和 7 个普通回路槽位，不能超过可用槽位数量。
- 已安装回路的槽位不能重复安装，必须先卸下或替换。
- 导力器属性值和导力魔法由当前回路配置派生，不由外部直接修改。
- 任务必须来源于地图、NPC 或剧情触发点之一。
- 任务状态必须按发布、受理、推进、完成的有效顺序变化。
- 城市地图中的 NPC、商店、任务和剧情触发点必须归属于明确地点。
- 背包中的物品数量不能小于 0。
- 商店必须归属于地图中的明确地点。
- 商店出售的物品购买成功后必须进入背包。
