# PRD 06 - 背包系统与商店购买

## 1. 背包系统

系统应支持维护角色背包中的物品。

背包物品至少应包括：

- 道具。
- 装备。
- 回路。
- 消耗品。

背包系统应满足：

- 背包物品必须有明确物品标识和数量。
- 背包物品数量不能小于 0。
- 增加物品时应累加数量。
- 扣减物品时不能超过当前持有数量。

## 2. 商店购买

系统应支持角色在城市地图中的商店购买物品，并将购买结果写入背包。

商店购买应满足：

- 商店必须归属于明确地点。
- 商店出售物品必须有明确物品标识。
- 购买数量必须大于 0。
- 购买成功后背包中对应物品数量增加。
- 不存在的商店或物品不能购买。
